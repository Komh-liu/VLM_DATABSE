# Qwen2.5-VL Technical Report

## One-line thesis

> Qwen2.5-VL 是 Qwen 视觉语言系列的旗舰版本，从零训练了原生支持动态分辨率的 ViT（Window Attention 降低计算量），引入绝对时间编码实现小时级视频定位，新增计算机和手机操控的 agent 能力，72B 版本在文档和图表理解上达到与 GPT-4o 和 Claude 3.5 Sonnet 平齐的水准。

## 架构改进（相对于 Qwen2-VL）

### 1. 原生动态分辨率 ViT（从零训练）

**Qwen2-VL 的限制**：动态分辨率虽然灵活，但 ViT 仍然基于固定分辨率预训练（如 CLIP 的 224×224/448×448），再做后处理适配。

**Qwen2.5-VL 的改进**：视觉编码器本身从零训练时就原生支持动态分辨率。

- 在 ViT 的所有自注意力层中支持任意大小的输入
- 引入 **Window Attention** 机制：在自注意力计算中限制每个 token 只关注局部窗口内的 token，将计算复杂度从 $O(N^2)$ 降为 $O(N \cdot W)$（$W$ 是窗口大小）
- 即使输入图像 token 数量大幅增加，计算成本增长速度远低于普通 ViT

**效果**：
- 对于高分辨率文档图像（如 A4 扫描件），可以生成更多视觉 token 而不显著增加计算量
- 在文档理解 benchmark 上提升显著

### 2. 绝对时间编码（Absolute Time Encoding）

**Qwen2-VL 的限制**：M-RoPE 虽然能编码视频帧的相对位置，但无法精确表达"第几秒"的绝对时间信息。

**Qwen2.5-VL 的改进**：引入绝对时间编码机制：

- 每个视频帧除了空间位置编码外，分配一个绝对时间戳编码
- 支持秒级的事件定位（如"找出视频中第 35 秒出现的物体"）
- 可处理长达数小时的视频

**效果**：在长视频理解和事件定位任务上能力大幅提升，支持从数分钟扩展到数小时的视频分析。

### 3. 视觉 Agent 能力

Qwen2.5-VL 新增了**交互式视觉 agent** 能力：

- **计算机操控**：理解屏幕截图，生成鼠标点击、键盘输入等操作指令
- **手机操控**：理解移动端 UI 界面，模拟用户操作
- **工具使用**：调用外部工具（搜索、计算器、翻译等）辅助完成任务
- **推理和决策**：在操作前进行多步推理规划

这是一个从"感知"到"行动"的重要能力扩展，使 Qwen2.5-VL 不仅是一个理解模型，也是一个能够操作数字世界的 agent。

### 4. 三档模型规模

| 模型 | 参数量 | 新增能力 | 适用场景 |
|------|--------|---------|----------|
| **Qwen2.5-VL-3B** | 3B | Agent 能力 | 边缘设备、agent 部署 |
| **Qwen2.5-VL-7B** | 7B | Agent 能力 | 通用场景 |
| **Qwen2.5-VL-72B** | 72B | Agent 能力 | 高性能场景 |

三个规模均具备 agent 能力，这是与 Qwen2-VL 的重要区别。

## 核心能力提升

### 1. 文档与图表理解（最大亮点）

| Benchmark | Qwen2.5-VL-72B | Qwen2-VL-72B | GPT-4o | Claude 3.5 Sonnet |
|-----------|---------------|-------------|--------|-------------------|
| **DocVQA** | 96.5 | 95.5 | 92.8 | 91.2 |
| **ChartQA** | 90.1 | 88.2 | 85.7 | 84.8 |
| **OCRBench** | 86.7 | 83.4 | 79.2 | — |
| **InfoVQA** | 84.3 | 78.2 | 71.5 | — |

基于原生动态分辨率 ViT，文档和图表理解能力全面超越 GPT-4o 和 Claude 3.5 Sonnet。在 InfoVQA 上的提升尤为显著（+6.1%），这直接受益于 Window Attention 支持的高分辨率处理。

### 2. 通用视觉理解

| Benchmark | Qwen2.5-VL-72B | Qwen2-VL-72B | GPT-4o |
|-----------|---------------|-------------|--------|
| **MMMU** (val) | 69.8 | 64.7 | 69.1 |
| **MathVista** (testmini) | 71.4 | 68.2 | 63.8 |
| **MMBench** (test) | 88.2 | 86.1 | 83.4 |
| **MMStar** | 71.6 | 68.0 | 62.5 |

在综合理解 benchmark 上持续提升，MMMU 超越 GPT-4o，MathVista 超过 GPT-4o 达 7.6%。

### 3. 视频理解

| Benchmark | Qwen2.5-VL-72B | Qwen2-VL-72B | GPT-4o |
|-----------|---------------|-------------|--------|
| **Video-MME** (w/o subs) | 77.8 | 71.2 | 71.9 |
| **MVBench** | 74.5 | 70.8 | — |
| **Video-MME** 长视频(>30min) | 68.3 | 53.2 | — |

绝对时间编码带来了视频理解的显著提升，特别是在长视频场景（>30 分钟）上提升达 15%。

### 4. 视觉 Agent 能力

- 在 **OSWorld**（计算机操控 benchmark）上表现领先于同规模模型
- 支持跨应用操作（如从网页复制内容到文档）
- 在 **GUI grounding** 任务上定位准确率超过专门训练的模型
- 手机 UI 操控在 Android 模拟环境中的任务完成率显著提升

### 5. 定位与感知能力

- RefCOCO testA: 87.3（Qwen2-VL: 83.9）
- 支持以点和框两种形式表示定位结果
- 新增标注置信度输出

## 关键技术创新总结

| 创新点 | Qwen2-VL | Qwen2.5-VL | 带来的提升 |
|--------|---------|-----------|-----------|
| ViT 训练 | 固定分辨率预训练 | 从零训练，原生动态分辨率 | 文档理解 +5~8% |
| 注意力机制 | 全注意力 | Window Attention + 全局 | 高分辨率下计算量可控 |
| 时间编码 | M-RoPE（相对） | M-RoPE + 绝对时间编码 | 长视频理解 +15% |
| Agent 能力 | 不支持 | 计算机/手机操控 | 新增操作能力 |
| 文档/图表 | 较好 | SOTA（超越 GPT-4o） | 主要优势领域 |

## 局限

- 72B 模型推理时需要的视觉 token 数量较大（高分辨率图像），推理延迟较高
- Agent 能力仍在早期阶段，复杂多步任务的成功率有限
- 长视频理解的绝对水平仍有提升空间
- 在某些细粒度任务上（如医学图像、卫星图像），领域专用模型仍更优

## 对后续工作的影响

Qwen2.5-VL 被大量多模态 RL 后训练工作用作基础模型（backbone）：
- **VisualRFT**（ICCV 2025）：以 Qwen2.5-VL 为 backbone 做视觉 RL 微调
- **MMUPT**（NeurIPS 2025）：无监督 GRPO 训练基于 Qwen2.5-VL-7B
- **R1-Reward**（ICLR 2026）：以 Qwen2.5-VL-7B 作为 reward model 的 backbone
- **BaseReward**（ICLR 2026）：扩展至 Qwen2.5-VL 7B/72B 做多模态奖励模型
- **PIVOT**（ICLR 2026）：以 Qwen2.5-VL 组件验证 DPO 对视觉编码器的重塑效果
